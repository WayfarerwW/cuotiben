# 错题本 Web 应用 UI 设计说明书

## 1. 设计概述

### 1.1 项目背景
为大学生打造高效、纯粹的错题管理工具。纯本地运行，FastAPI + Vue3 + Element Plus，数据隐私安全，操作流畅。

### 1.2 设计目标
- **简洁**：去除冗余装饰，聚焦核心内容
- **高效**：优化操作路径，支持快捷键与批量操作
- **专注**：沉浸式色彩与布局，营造心流体验

### 1.3 设计原则
- **内容优先**：界面服务于题目内容
- **一致性**：统一组件规范与交互逻辑
- **反馈即时**：所有操作都有明确视觉反馈
- **本地优先**：UI 状态与数据同步适应本地存储

### 3.2 侧边栏

- **功能导航区**：首页、题目管理、今日复习、记事本、统计分析、设置。激活项主色背景 + 白色文字
- **学科文件夹树**：两级（学科 → 大类），支持拖拽排序、右键菜单
- **用户信息区**：固定底部，头像 + 昵称 + 本地存储状态
- **折叠交互**：点击折叠为 64px 图标模式，悬停显示 Tooltip

### 3.3 顶部导航栏

- **搜索框**：居中或左对齐，支持全局搜索，快捷键 Ctrl/Cmd + K
- **操作按钮**：右侧「新增题目」主按钮、「导出 PDF」次按钮
- **通知铃铛**：带红点或数字角标，点击展开通知面板
- **用户菜单**：头像 + 下拉

### 3.4 主内容区

- 页面标题区：标题 + 面包屑 + 页面级操作
- 统计卡片行：4 列网格
- 数据表格区：主要垂直空间，支持虚拟滚动
- 空状态：插画 + 引导文案 + 操作按钮


## 4. 核心页面设计

### 4.1 首页概览

- **统计卡片**：总题目数、今日待复习、已掌握、仍易错。带趋势箭头与迷你图
- **今日复习推荐**：前 5 条待复习题目，点击进入复习
- **快捷操作入口**：快速录入、随机复习、查看笔记

### 4.2 题目管理

**表格列**：多选框 | 题干预览 | 所属文件夹 | 标签 | 重点星标 | 掌握状态 | 更新时间 | 操作

- 支持列宽拖拽、排序、自定义显示列
- 工具栏：搜索框 + 标签筛选 + 排序下拉 + 批量操作
- 分页：底部居中

**新增题目弹窗**：
- 表单：题干（富文本/Markdown）、答案、解析、文件夹、标签、难度、重点
- 底部：保存 / 保存并继续添加 / 取消

**题目详情弹窗**：只读展示，支持编辑、删除、复制

### 4.3 今日复习

- **进度条**：顶部渐变横幅（主色 → 辅助色），显示已完成/总数
- **题目内容区**：
  - 题干：支持图片放大、公式渲染
  - 标签与元信息：灰色小字
  - 答案：默认折叠，点击"显示答案"展开，带淡入动画
- **复习评价按钮组**：
  - 4 个按钮横向：完全不会（红）/ 有点模糊（橙）/ 基本掌握（蓝）/ 已掌握（绿）
  - 点击后即时反馈（缩放 + 颜色填充），自动切下一题
  - 上一题/下一题，支持键盘方向键
- **完成状态**：庆祝插画 + 统计摘要 + 返回首页

### 4.4 记事本

- **左右分栏**：
  - 左侧列表（300px）：标题 + 内容预览 + 更新时间，支持搜索与新建
  - 右侧编辑器：标题输入框 + 内容文本域（Markdown 编辑/预览切换）
- **草稿自动保存**：右上角显示"已自动保存 · 刚刚"，淡入淡出动画
- **草稿恢复提示**：检测到草稿时顶部橙色提示条，提供"恢复"/"忽略"

### 4.5 统计分析

- 统计概览卡片：本周复习时长、新增题目数、掌握率、连续打卡天数
- 图表：
  - 饼图：学科分布
  - 折线图：复习趋势（近 30 天）
  - 词云：高频标签
  - 柱状图：每日新增 vs 复习量

### 4.6 设置页

- 左侧导航：记忆曲线参数 / 复习设置 / 外观主题 / 数据管理 / 关于
- 右侧设置表单
- 数据说明页：数据库大小、备份/恢复入口、清除缓存


## 5. 组件设计规范

### 5.1 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| 主要按钮 | #4A7CDB 填充 + 白字 | 保存、确认、新增 |
| 次要按钮 | 白底 + #E2E8F6 边框 | 取消、导出、筛选 |
| 危险按钮 | #FC8181 填充 + 白字 | 删除、清空 |
| 文字按钮 | 无边框 + 主色文字 | 查看详情、更多 |
| 图标按钮 | 圆形/方形 + 图标 | 刷新、设置、关闭 |

状态：默认 → 悬停（亮度 +10%）→ 激活（亮度 -5%）→ 禁用（透明度 50%）→ 加载（Spinner + 禁用）

### 5.2 标签系统

- **学科标签**：学科主题色背景 + 深色文字
- **重点标签**：#F6AD55 背景 + 图标
- **困难标签**：#FC8181 背景 + 图标
- **样式**：默认圆角 6px，胶囊模式 20px
- **创建**：输入框回车创建，支持下拉联想，点击 x 删除

### 5.3 状态标识

- **重点星标**：黄色 #F6AD55，未重点为灰色轮廓
- **正误状态**：
  - 仍易错：红色圆点 + #FC8181 文字
  - 已拿下：绿色圆点 + #68D391 文字
- **复习状态**：
  - 待复习：蓝色标签
  - 已复习：灰色标签
  - 逾期：红色标签 + 图标
  - 积压：橙色标签 + 数字
- **通知角标**：
  - 红点：仅表示有新通知
  - 数字角标：≤99 显示数字，>99 显示 99+
  - 橙色角标：警告类
  - 红色角标：错误/紧急

### 5.4 通知面板

- 下拉面板：从铃铛下方展开，宽 360px，最大高 480px，可滚动
- 通知项：左侧色条（未读）+ 标题 + 摘要 + 时间 + 操作按钮
- 未读标识：左边框 3px 主色
- 复习视图内嵌：通知面板内直接展开复习视图，不遮挡内容


## 6. 交互设计规范

### 6.1 导航交互

- 侧边栏折叠/展开：宽度过渡 300ms ease-in-out，内容区自适应
- 页面切换：淡入淡出 200ms
- 文件夹树展开/收起：高度动画 250ms，箭头旋转 90°
- 面包屑：末级不可点击，中间级悬停下划线，溢出时省略号 + Tooltip

### 6.2 表单交互

- 输入框焦点：边框变主色 + 外发光 `0 0 3px rgba(74,124,219,0.2)`
- 标签输入：回车创建后清空，动画插入；点击 x 缩放移除
- 草稿自动保存：停止输入 500ms 触发，保存期间显示加载态
- 草稿恢复提示：页面加载时检测，顶部滑入提示条，5s 后自动收起

### 6.3 复习交互

- 进度条动画：数值变化平滑过渡 500ms，渐变随进度变化
- 答案展开/收起：高度动画 300ms ease，图标旋转
- 复习评价反馈：点击后 scale(0.95) → scale(1) + 背景填充，200ms 后自动切题
- 上一题/下一题：内容区左右滑动 250ms，支持键盘方向键
- 打勾即时反馈：对勾绘制动画，行背景短暂高亮

### 6.4 反馈机制

- 成功 Toast：绿色，顶部居中，3s 消失
- 警告 Toast：橙色，顶部居中，手动关闭或 5s 消失
- 错误 Toast：红色，顶部居中，手动关闭
- 确认对话框：居中弹窗，遮罩 rgba(0,0,0,0.5)，标题 + 描述 + 双按钮，支持 Esc 关闭


## 7. 响应式设计

| 断点 | 布局策略 | 关键调整 |
|---|---|---|
| 桌面端 >1200px | 完整三栏 | 侧边栏固定 260px，内容区自适应 |
| 平板端 768-1200px | 可折叠侧边栏 | 默认折叠为 64px，点击展开 |
| 移动端 <768px | 抽屉式侧边栏 | 侧边栏隐藏，汉堡菜单触发抽屉；表格转卡片列表；顶部导航简化 |


## 8. 可访问性

- 颜色对比度 ≥4.5:1（WCAG AA），状态色配合图标/文字
- 键盘导航：所有交互元素支持 Tab 聚焦，Enter/Space 触发，Esc 关闭弹窗
- 焦点指示器：`outline: 2px solid #4A7CDB; outline-offset: 2px`
- 语义化 HTML：`<nav>`、`<main>`、`<article>`、`<button>`，ARIA 属性标注状态
- 屏幕阅读器：图标按钮提供 aria-label，状态变更用 aria-live 播报
